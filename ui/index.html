BOM spreadsheets

Each spreadsheet (.xlsx, .csv, .txt) in this folder is one product. Code and description come from the file name.
e.g. "BOM - " for "BOM - ABC-100 - Side table.xlsx"
One details spreadsheet per product, in the BOM folder, joined by part code.

Column names

Alternatives separated by |. Case, accents and punctuation are ignored. All other columns are shown as they are.

File types

Several types may share one folder: files are told apart by extension. Separate several folders with ";". "Prefix" also finds "ABC-100 - Side.pdf" and "ABC-100_rev2.pdf" for code ABC-100 (but never "ABC-1000").
